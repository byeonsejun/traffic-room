# 전국 도로 상황실 검색 노출(SEO · AEO · GEO) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** 관제 화면(`/`)과 분석(`/insights`)이 검색 결과 · 공유 카드 · AI 검색에서 제대로 소개되게 하고, 지금 틀린 "약 1시간 지연" 설명을 실제 설정(20분)과 같게 만든다.

**Architecture:** 운영 주소 · 사이트 이름 · 미리보기 판정 · 페이지 메타 조립을 `apps/web/src/lib/seo.ts` 한 곳에 둔다. 지연 문구는 화면과 같은 `readTiming(process.env)` + `delayLabel` 에서 만든다(빌드 시점 값). 공유 이미지는 Next 파일 규칙(`app/opengraph-image.png`)으로 두 페이지에 같이 건다. JSON-LD 는 서버 컴포넌트인 `page.tsx` 가 `<script type="application/ld+json">` 으로 넣는다.

**Tech Stack:** pnpm 모노레포, Next.js 16.4.6(App Router, cacheComponents 없음), React 19.3, TypeScript 7, Vitest 5, oxlint(`--deny-warnings`).

**Spec:** 포트폴리오 저장소의 `docs/superpowers/specs/2026-11-20-seo-aeo-geo-design.md` §2 · §4.5 · §4.7 · §5

## 조사 결과 (2026-11-25)

- 운영 `https://traffic-room.vercel.app` 의 `/robots.txt` · `/sitemap.xml` · `/llms.txt` 모두 404. canonical · 공유 카드 · JSON-LD 없음.
- 루트 설명이 `전국 돌발 상황을 약 1시간 지연으로 보여주는 도로 상황실` — 실제는 20분이다(`/api/snapshot` 응답 `delayMinutes: 20`, Vercel 환경변수 `DELAY_MINUTES`).
- 운영 Lighthouse 13.4.1 모바일 SEO 기준선: `/` 100, `/insights` 100(실패 감사 없음). → 문서에 "점수를 올렸다"고 쓰지 않는다.

## Global Constraints

- 구조화 데이터 · 메타에는 화면에 보이는 값만 쓴다(위 "조사 결과"). 숫자는 설정에서 읽고 지어내지 않는다.
- 새 클라이언트 JS 금지. 새 `'use client'` 파일 없음. JSON-LD 는 서버 컴포넌트가 HTML 에 넣는다.
- 정본 주소는 상수 `SITE_URL = "https://traffic-room.vercel.app"`. 미리보기에서도 canonical 은 운영을 가리킨다.
- 미리보기 판정은 `VERCEL_ENV === "preview"` 만. 그때만 루트 `robots: { index: false, follow: false }` 와 robots.txt `Disallow: /`. 로컬 · 운영은 색인.
- 운영 robots 는 `/api/` 만 막는다. AI 검색 로봇은 따로 막지 않는다.
- 레이아웃 `openGraph` 에 `description` 을 넣지 않는다(Next 는 페이지 openGraph 가 레이아웃 것을 통째로 대체한다 — 페이지마다 전체 openGraph 를 만든다).
- 비용 0원, 키 · DB 주소를 출력하지 않는다(기존 규칙). 개발 · 테스트에서 ITS 를 부르지 않는다.
- 게이트: 저장소 루트에서 `pnpm -r typecheck`, `pnpm -r lint`, `pnpm test`, `pnpm --filter @traffic-room/web build`. Next 빌드가 SecurityFatalError(업그레이드 권고)로 멈추면 한 번만 다시 돌린다. Next 업그레이드 금지.
- `apps/web/AGENTS.md`: 이 Next 는 학습 데이터와 다르다 — 메타데이터 파일 규칙은 `apps/web/node_modules/next/dist/docs/01-app/03-api-reference/03-file-conventions/01-metadata/` 의 `robots.md` · `sitemap.md` · `opengraph-image.md` 를 먼저 읽는다.
- 커밋: `feat:`/`fix:`/`docs:` + 한국어 제목, 본문 2~5줄(왜 · 무엇을 확인했는지), 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. 면접관이 읽는 글이라 사람이 쓴 문체로.
- 공개 문서(README · 커밋 · PR)에 저장소 밖 경로를 쓰지 않는다. 구글 리치 결과 테스트는 자동화하지 못하니 "했다"고 쓰지 않는다.
